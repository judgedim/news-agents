# NewsAgents - Система Мультиагентного Збору та Обробки Новин

NewsAgents - це мультиагентна система для збору, обробки, перекладу, категоризації та аналізу технологічних новин. 
Система використовує різні джерела даних (RSS-потоки, Tavily API, веб-скрапінг) та можливості великих мовних моделей (LLM) для створення зведень актуальних новин.

## Можливості системи

- **Збір новин** з різних джерел:
  - RSS-потоки українських та світових медіа
  - Tavily API Search для пошуку актуальних новин
  - Веб-скрапінг українських ресурсів

- **Обробка новин**:
  - Переклад новин українською мовою
  - Аналіз тональності статей (позитивна/негативна/нейтральна)
  - Категоризація за тематиками
  - Створення стислих дайджестів

- **Зберігання та візуалізація**:
  - Збереження у SQLite БД
  - Генерація HTML-звітів

- **Асинхронність і паралелізм**:
  - Підтримка як синхронної, так і асинхронної роботи
  - Паралельна обробка для підвищення швидкодії

## Агенти системи

1. **CrawlerAgent** - збір новин з RSS-потоків
2. **TavilyAgent** - пошук актуальних новин через Tavily API
3. **WebScraperAgent** - скрапінг українських новинних сайтів
4. **TranslatorAgent** - переклад новин українською мовою
5. **SentimentAnalysisAgent** - аналіз тональності статей
6. **CategorizerAgent** - класифікація статей за категоріями
7. **SummarizerAgent** - створення коротких дайджестів
8. **StorageAgent** - збереження статей у SQLite базу даних
9. **HTMLReporterAgent** - створення HTML-звітів

## Схема взаємодії агентів

Система побудована на принципі послідовної обробки даних з можливістю паралельного виконання деяких етапів:

```
                                   ┌─────────────────┐
                                   │                 │
                                   │  CrawlerAgent   │
                                   │  (RSS-потоки)   │
                                   │                 │
                                   └────────┬────────┘
                                            │
                                            ▼
┌─────────────────┐                 ┌─────────────────┐                 ┌─────────────────┐
│                 │                 │                 │                 │                 │
│  TavilyAgent    │────────────────▶│  Об'єднання    │◀────────────────│ WebScraperAgent │
│  (Tavily API)   │                 │  новин         │                 │ (Веб-скрапінг)  │
│                 │                 │                 │                 │                 │
└─────────────────┘                 └────────┬────────┘                 └─────────────────┘
                                            │
                                            ▼
                                   ┌─────────────────┐
                                   │                 │
                                   │ TranslatorAgent │
                                   │ (Переклад)      │
                                   │                 │
                                   └────────┬────────┘
                                            │
                                            ▼
                          ┌─────────────────────────────────┐
                          │                                 │
           ┌──────────────┤      Паралельна обробка        ├──────────────┐
           │              │                                 │              │
           │              └─────────────────────────────────┘              │
           ▼                                                              ▼
┌─────────────────┐                                               ┌─────────────────┐
│                 │                                               │                 │
│CategorizerAgent │                                               │SentimentAnalysis│
│(Категоризація)  │                                               │Agent (Тональн.) │
│                 │                                               │                 │
└────────┬────────┘                                               └────────┬────────┘
         │                                                                │
         └────────────────────────┬────────────────────────────────────────┘
                                  │
                                  ▼
                         ┌─────────────────┐
                         │                 │
                         │ SummarizerAgent │
                         │ (Дайджести)     │
                         │                 │
                         └────────┬────────┘
                                  │
                                  ▼
                         ┌─────────────────┐
                         │                 │
                         │  StorageAgent   │
                         │  (SQLite БД)    │
                         │                 │
                         └────────┬────────┘
                                  │
                                  ▼
                         ┌─────────────────┐
                         │                 │
                         │HTMLReporterAgent│
                         │(HTML-звіти)     │
                         │                 │
                         └─────────────────┘
```

Процес обробки новин:

1. **Збір даних**: Три агенти (CrawlerAgent, TavilyAgent, WebScraperAgent) паралельно збирають новини з різних джерел
2. **Об'єднання**: Результати збору об'єднуються в єдиний потік даних
3. **Переклад**: TranslatorAgent перекладає новини українською мовою
4. **Аналіз**: CategorizerAgent і SentimentAnalysisAgent паралельно аналізують тексти
5. **Узагальнення**: SummarizerAgent створює короткі дайджести статей
6. **Зберігання**: StorageAgent зберігає оброблені дані в SQLite базу даних
7. **Звітність**: HTMLReporterAgent генерує HTML-звіт з результатами

## Встановлення та налаштування

1. Клонуйте репозиторій:
   ```
   git clone https://github.com/yourusername/newsagents.git
   cd newsagents
   ```

2. Створіть та активуйте віртуальне середовище:
   ```
   python -m venv venv
   source venv/bin/activate  # для Linux/Mac
   venv\Scripts\activate  # для Windows
   ```

3. Встановіть залежності:
   ```
   pip install -r requirements.txt
   ```

4. Створіть файл `.env` з налаштуваннями:
   ```
   OPENAI_API_KEY=ваш_ключ_openai
   TAVILY_API_KEY=ваш_ключ_tavily
   SCRAPINGBEE_API_KEY=ваш_ключ_scrapingbee
   UCRAWLER_API_KEY=ваш_ключ_ucrawler
   ```

- Заголовок і посилання на оригінал статті
- Джерело
- Тональність (позитивна/негативна/нейтральна)

## REST API для мобільного додатку

Система містить простий REST API для отримання останніх новин з авторизацією через Bearer Token (персональний токен для вашого мобільного телефону).

### Запуск API

1. Встановіть залежності:
   ```bash
   pip install fastapi uvicorn python-dotenv
   ```
2. Додайте у файл `.env`:
   ```
   API_TOKEN=supersecrettoken
   ```
3. Запустіть сервер:
   ```bash
   uvicorn news_api:app --reload
   ```

### Використання з мобільного додатку

- Робіть GET-запит на:
  ```
  http://<ваш_сервер>:8000/news?limit=10
  ```
- Додавайте заголовок:
  ```
  Authorization: Bearer supersecrettoken
  ```

**ВАЖЛИВО:**
- Тримайте токен у таємниці! Якщо телефон втрачено — змініть токен у .env і перезапустіть сервер.
- .env не має потрапляти у git!

## Тестування

Система має комплексне тестове покриття для всіх компонентів. Тести розділені на три основні категорії:

### 1. Тести агентів (test_agents.py)

Перевіряють функціональність кожного агента окремо:
- **CrawlerAgent**: тестування отримання новин з RSS-потоків
- **TranslatorAgent**: тестування визначення мови та перекладу
- **SummarizerAgent**: тестування створення дайджестів
- **SentimentAnalysisAgent**: тестування аналізу тональності
- **WebScraperAgent**: тестування отримання HTML-сторінок
- **StorageAgent**: тестування збереження та отримання статей з бази даних

### 2. Тести системи (test_system.py)

Перевіряють взаємодію агентів у рамках системи:
- **TestSyncFlow**: тестування синхронного потоку обробки новин
- **TestAsyncFlow**: тестування асинхронного потоку обробки новин
- **TestEndToEndFlow**: інтеграційні тести з реальними даними

### 3. Тести API (test_news_api.py)

Перевіряють функціональність REST API:
- **TestNewsAPI**: тестування авторизації та отримання новин через API

### Запуск тестів

```bash
# Запуск усіх тестів
python -m unittest discover tests

# Запуск конкретного тестового файлу
python -m unittest tests/test_agents.py
python -m unittest tests/test_system.py
python -m unittest tests/test_news_api.py
```
